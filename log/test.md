## 20412 윤성민
0차시: 주제 선정: 년도마다 폐교를 한 학교의 수는 어떻게 변화했을까?(초,중,고 따로) 또한 각 시마다 따로 분류한다.

데이터는 공공데이터포탈 한국교육학술정보원 학교알리미 폐교정보로 선정이유는 다양한 방식(csv,json등)으로 다운로드 할 수 있고 가장 전국적인 데이터를 볼 수 있기 때문이다.

1차시 : 자료를 정리하고 어떤 방법으로 질문을 해결할지 고민했다.

2차시 : 주어진 데이터로 어떻게 포스터를 구상할지 생각했다. 특별히 폐교한 학교의 수가 줄어든 지역이 있다면 어떤 이유가 있을 수 있는지 생각해보았다.

3차시 : 깃허브와 생성형 인공지능으로 대략적인 앱 완성
대전 지역의 그래프가 이상해서 이유를 찾아봤더니 데이터의 개수가 3개밖에 없어 데이터가 부족하다는 것을 발견. 또한 예상한 것과 다르게 폐교한 학교의 수가 선형일 것이라 예상했지만 계속 증가하거나 감소하는 형태가 아닌 계속 바뀌는 형태였음.
그렇기에 선형만으로는 예측을 하기 어려울 것이라 생각.

2차시: 발표, AI로 깃허브 코드 만드는 프롬프트 조금 구상함
